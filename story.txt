#  Starters are the Pokemon with "starter = yes" in their pokemon.txt.
#  (A "starters = A, B, C" line here is only used if none are tagged.)
#  start_level = their level
#  training_reward_every = training-battle wins per new creature
#
#  Each [stage] is one trainer battle, unlocked in order:
#    name    = place name           trainer = who you fight
#    say     = their line before the battle
#    team    = creature names, "random", or "random <Type>" (comma separated).
#              The team is used as written (1-6 creatures).
#    level   = CPU levels relative to your team's average (e.g. -2, 0, +3)
#    cpu     = easy / normal / hard
#    reward  = yes / no   (win: choose a new creature)
#    arena   = stadium, rock, water, electric, grass, poison, psychic, fire, ground
#    badge   = badge won here (makes it a gym: no catching, big coin prize)
#    catch   = yes / no   (after a win, try to catch one of their creatures;
#              default yes for trainers, no for gyms)
#    coins   = coins for winning (default: worked out from the level)
#    map     = x, y   where the stage sits on the map image (in image pixels)
#    outdoor = yes   gyms are indoor arenas (no weather, lit at night); this makes one outdoors
#    venue   = where a non-gym battle is drawn: route, forest, cave, ice cave, beach, city, bridge,
#              ship, park, dojo, office, tower, mansion, volcano, hideout, lab, mountain, stadium
#              (default: worked out from the stage name)
#
#  map_image = picture shown as the Story Mode map (next to this file);
#              without one the game draws a simple map.
#  town      = name, x, y   (labels on the map)
#  rare_every        = every Nth training battle is a rare creature to catch
#  training_max_foes = most opponents in a normal training battle
#  Rival battles (rival = yes): "rival" in a team is the rival's starter (the type that beats
#  yours; in co-op, the starter neither of you took), evolved for its level. "rival_partner" is
#  his Pikachu (co-op only). "rival_trio1" / "rival_trio2" are two of Growlithe, Exeggcute and
#  Gyarados, picked by his starter like in Red/Blue. Any team entry can end in +N / -N levels.
#  story_rev = 3   layout version (lets old saves keep their place when stages are added)
# ==========================================================================
