# ==========================================================================
#  POKEMON TEMPLATE
# ==========================================================================
#  HOW TO ADD A POKEMON
#   1. Copy this whole _TEMPLATE folder and rename the copy to the Pokemon's
#      name, e.g.  Pokemon\Ivysaur
#   2. Put its sprite images in the folder (see SPRITES below).
#   3. Fill in every value below and save.
#   4. Start the game. Pokemon\load_log.txt shows what was read and any mistakes.
#
#  Folders whose name starts with _ (like this one) are ignored.
#  Anything after a # is a note and is ignored.
#
#  SPRITES - files are matched by the direction word in their name:
#     front:  front, mae, down        back:  back, ushiro, up
#     left:   left, hidari            right: right, migi
#  followed by _1 / _2 for the two walking frames, e.g.
#     001_1_mae_1.png   001_1_mae_2.png   front_1.png   left.png
#  Grid-chart pictures work as-is. Numbered copies ("_No" in the name) are used
#  first; plain copies are the backup. A picture with no direction word becomes the
#  menu portrait. Missing left/right views are mirrored from each other.
# ==========================================================================
