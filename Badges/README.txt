GYM BADGE PICTURES
==================
Put a picture for each badge in this folder and the game shows it on the hub, the Map and
the gym intro (dark until you win it). Without a picture the badge is a colored hexagon.

The file name only has to contain the badge's name, for example:
    Boulder.png   Cascade.png   Thunder.png   Rainbow.png
    Soul.png      Marsh.png     Volcano.png   Earth.png

Plain pictures (PNG with a transparent background) work, and so do pixel-art charts
(a numbered grid of colored squares, like the Pokemon pictures) - a chart whose file name
ends in _No (Boulder_No.png) is read first, since the numbers help.

Badge names come from the "badge =" lines in story.txt, so a new gym's badge works the same way.
